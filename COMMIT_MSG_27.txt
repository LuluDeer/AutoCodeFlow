chore(release-desktop): bump executor-desktop 1.5.3 → 1.5.4

为什么必须发这一版：desktop-v1.5.3 出包后，main 上又合入了 **10 个改动桌面端
/ 内嵌执行器代码的 commit，全部未进安装包**（已逐个 `git merge-base
--is-ancestor <c> desktop-v1.5.3` 核实均为 NOT in 1.5.3），51 文件 /
4002 插入行，提交类型为 10 fix + 2 perf + 1 chore（**0 个 feat** → 按语义化
版本为 patch，故 1.5.4）。

用户可感知面（即 1.5.3 装机用户当前缺的能力）：

  8093d3ec  内嵌 executor-node **回调落盘原子化**（tmp→rename）——半写文件被判
            corrupt payload 毒丸死信后，该执行器**整批任务终态永久丢失**（含
            同批无关的成功任务），且 4xx 不可重试。**最严重的一条**。
  bafc9a61  渲染树外层包全局 ErrorBoundary——渲染期异常此前直接**整窗白屏**。
  ffc99f7c  HistoryPage 日志读取 try/catch/finally——readLog reject 时永久
            「加载中」且每 1.5s/5s 重复 unhandled rejection（catch 终止轮询）。
  1a70284a  ConfigPage 首屏 Promise.all 补 catch——配置损坏时永久「加载中」。
  cb5824c3  logs:getToday 改尾部窗口读——整读整天日志**卡死主进程**。
  5882a082  子进程输出按行缓冲——多行/半行 chunk 致结构化日志通道**静默失效**。
  fcda92ab  降优先级改用 os.setPriority——废除一次性 spawn powershell。
  ea31f78b  history:get/notifier 同步 readFileSync 改 fs.promises+Promise.all；
            meta-files 候选无截断。
  另含 executor-node 侧 NETOPT-5/6/8 多个修复（TOTP 重放防护、zip 下载双层
  超时、requirements 解析剥 BOM、池 LRU 回收在跑否决权等）与
  **bundle 重打**（见下）。

本次 bump 顺带把一个**清单漂移**收敛掉了（如实界定，勿夸大）：1.5.3 出包时
清单与源码**是自洽的**（dc8abcda… 对应当时的 EXP-02 源码 5ba2b81e，已用
`git show desktop-v1.5.3:...` 核对）。漂移发生在**其后**：c41fd22d（新增
/app-uninstall）与 d74355aa（NETOPT-F）两次改 executor-node/src 都没重打
bundle，CI 的 desktop-bundle-drift 一直到本轮才报红——即若不做本轮修复直接打
1.5.4 tag，安装包会**带着漂移的清单**出厂（产物与源码不符，正是该闸要拦的
形态）。本轮已按 ADR-005 重打并回填 239bbd2e…（本机重打 / CI 侧重打 / 清单
三方逐字节一致）。

改动形态与上一轮 desktop bump（#18）一致：package.json 的 version 行 +
package-lock.json 的第 3/9 行，共 3 行；两文件 JSON 已校验合法。

注：apps/executor-desktop/README.md 里出现的 "desktop-v1.5.x" 是**历史踩坑
记录**（NSIS 校验需先取嵌套 app-64.7z），不是版本声明，保持不动。
