fix(desktop): Python 环境诊断在保存配置后不刷新，页内显示旧值（EXP-06）

缺陷（ConfigPage 的「Python 运行环境」页）：诊断块（uv 路径 / 解释器池目录 /
池内版本清单 / 下载预算）拉取 effect 的依赖只有 `[active]`，于是**只在切页时
拉一次**。用户在这一页改完 uvPath、解释器池目录或下载预算并点「保存配置」后，
诊断块**仍显示旧值**。

而诊断块存在的全部意义就是回答"我配的到底生效了没有"（其自身注释也写明：
Python 环境的失败模式几乎全是"配置看起来对、实际没生效"）。改完不刷新 →
用户怀疑保存没生效而反复保存，或带着错误认知去排障（看到 uv 路径没变、
池里仍显示空）。这类缺陷不会报错、不变红、无日志，只是让页面上显示的信息与
真实状态不一致——本轮已多次遇到同形态（EXP-03 / EXP-05）。

修法：把拉取逻辑抽成 `refreshPyEnv()`，切页时照旧调用（原行为保留），并在
**保存成功后**再调一次。只在成功分支调用：失败时保留上一次诊断，比清空更有
参考价值。

验证：desktop test:renderer / test:main 全部通过；tsc --noEmit 0 error。
反证（renderer.selftest 新增 EXP-06 段）：
  · 断言 refreshPyEnv() 存在、save() 里调用了它、且调用点在保存成功分支
    （`setSaved(true)` 之后）而不是失败分支；
  · 断言切页路径仍调用 refreshPyEnv()——防止"修了保存后刷新、弄丢了切页刷新"；
  · 已实测：删掉保存后那次调用 → 守卫报红并直接点名「改完配置诊断仍显示旧值」。
