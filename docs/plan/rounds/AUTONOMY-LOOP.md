# AUTONOMY-LOOP — 自治优化循环手册

> 主会话 = 调度器，不是工人。工作内存放在**子代理**与**磁盘**，不放在主会话上下文里。
> 本文件是每个新会话的第一读；读完再读 `AUTONOMY-STATE.md`（≤40 行）即可无损接管。

## 1. 主会话每轮硬预算（≤8 次工具调用）

只允许读三样，其余一律派子代理：

| # | 允许项 | 上限 |
|---|---|---|
| ① | 本文件 `docs/plan/rounds/AUTONOMY-LOOP.md` | 全文 |
| ② | 状态卡 `docs/plan/rounds/AUTONOMY-STATE.md` | 全文 |
| ③ | git 摘要 `git status --short` + `git log -1` | 20 行 |

**禁止在主会话读**：代码正文、完整测试输出、diff、日志、审计报告全文。
需要这些一律派子代理，长产物落盘 `artifacts/autonomy/R<NN>/`，回执只取 **≤15 行结构化摘要**。
超预算 = 本轮记账失败，下轮收尾并交接。

## 2. 一轮六步（缺一步不算一轮）

1. **评估** —— 读状态卡 + 台账末条 + backlog，列出候选（不在主会话做，派子代理产出 `assess.md`）。
2. **立项（只选 1 项）** —— 写 `artifacts/autonomy/R<NN>/brief.md`，四要素齐全：
   - 一句话缺陷/收益（带 `文件:行号` 或命令证据）
   - 文件足迹（预计改哪些文件/目录，用于写域互斥判定）
   - 验收判据（**红→绿的用例名**，或**命令 + 期望 exit code**；二者必居其一）
   - 回滚方式（`git revert <sha>` / 单文件还原 / 迁移回滚路径）
3. **分批落地** —— 每批不超过一个可独立验证的改动；写域与其他代理互斥。
4. **验证** —— 真机或单测跑通。**未跑真机必须标 `unverified`，禁止写「已验证」。**
5. **台账登记** —— `docs/PLAN-CLAIMS.md`（认领板，唯一事实源）追加本轮条目。
6. **复盘** —— 状态卡刷新「下轮第一步」+ 1 条方法学沉淀；未修项进 `AGENT-SWARM-PLAYBOOK.md` §7。

**验证没过不许开下一项。**

## 3. 证据纪律

- 每条结论带 **`文件:行号`** 或 **`命令 + 真实 exit code`**。
- 提交前 `git diff --cached --stat`；`git add`/`git restore` **只用显式路径**，禁止 `-A`
  （本仓常有并行会话的未提交改动，先读再收编）。
- 「没做」「没跑」「只做到一半」要如实写进台账，不许用完成态措辞覆盖。

## 4. 编排升档（默认最低档）

| 档位 | 触发条件 |
|---|---|
| **1 个 subagent（默认）** | 单点增量；优先复用同一会话续跑，省重复探查 |
| **team ≤3** | 需并行且**写域互斥**（文件/目录不重叠） |
| **workflow** | **同构项 >5**（同类批量迁移/审计），且用 schema 收敛返回体 |

**升档必须先在状态卡写一句理由**，否则维持默认档。

派发子任务时必须显式写清（不要假设子代理会读 AGENTS.md）：
1. `AGENTS.md §1 CodeGraph 优先`：MCP `codegraph_explore` → 退化 `codegraph explore` CLI；
2. `projectPath`（本仓根 `/home/yongsheng/project/AutoCodeFlow`）；
3. 只读域 / 写域（互斥声明）；
4. 验证命令 + 期望 exit code；
5. 输出 schema（回执 ≤15 行，长产物落盘路径）。
子模型深度 8，允许子代理再调子代理；单批并行工具调用 ≤20。

## 5. 台账三分工

| 落点 | 内容 |
|---|---|
| `docs/PLAN-CLAIMS.md` | 进行中 / 结项（认领板，唯一事实源） |
| `AGENT-SWARM-PLAYBOOK.md §7` | 未修项 backlog |
| `docs/AGENT_HANDOFF.md` | 每轮收尾追加状态快照 |

**过期 finding 直接删或标「已被 HEAD 推翻」**，不背历史包袱滚动。

## 6. 止损

- 同一阻塞**连续 3 轮未解** → 记 `blocked`，换靶。
- **验证失败 2 次 → 回滚**，不许第 3 次硬试。
- 破坏性重构（改 schema / 迁移 / 公共 API / 删除模块）**必须先写 ADR**
  （含数据迁移守规 `check-migrations` + 回滚路径），否则不做。

## 7. 轮换信号（任一命中即进入收尾轮）

- 本轮上下文**已被压缩过一次**；
- **连续两轮**工具输出被截断；
- 本会话**轮数 ≥6**。

收尾轮**只做交接**，不做新增量：
1. 刷新状态卡「下轮第一步」，使新会话无需回溯即可接管；
2. `goal` 置 `pause`；
3. 输出 3 行交接结论 + 提示用户开新会话继续。

## 8. 每轮对外输出（≤6 行）

`本轮结论 / 证据 / 改动文件 / 遗留 / 下轮第一步` —— 不贴代码、不贴日志。
