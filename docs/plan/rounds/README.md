## 为什么单独放

`PLAN-CLAIMS.md` 原 **3420 行**，其中历史轮次与里程碑复盘占 **2561 行（75%）**，而日常只读前 859 行
（找任务、认领、查迁移号）。拆开之后：

- **认领板短**：打开就是表，不用滚过两千行复盘；
- **历史更可读**：按轮次切成小文件，单篇 **65–584 行**；
- **判据不受影响**：迁移登记留在原位，`check-migrations` 的解析面一字未动。
