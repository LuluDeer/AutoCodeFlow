## 教训（424–425，接 423）
- **424「降级类动作的日志要三态：没活 / 干成了 / 想干但干不动」** —— 第三态最容易被「别刷日志」的善意吞掉，而它恰恰是**唯一**需要人知道的一态。
- **425「探针断言条件不能跨两行日志用 `&&`」** —— 逐条日志与汇总日志字段互斥，组合条件永不满足；这是探针的 bug 不是产品的。修探针前先数「到底几行日志、各含什么」。
