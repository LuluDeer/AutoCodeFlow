## 教训（累积，本轮新增）
**守卫的头注承诺要与实现一致**（`?.` ≠ `&&`/`if`；`name?:` ≠ `| undefined`）；**定向 pattern 覆盖面本身要复核**；**审计"0 条"也要给统计**（61/5/1/19/19 五形态计数 + 抽检理由），否则无法区分"真的干净"与"没扫到"；**基线只来自真跑**（不能为了让文档好看而手改数字）。

## 方法学
只信「命令 + 真实 exit code」；**零回填要用「迁移前就存在的行」证明**；**写域边界 = 停手 + 给可粘贴内容**；**「判据没红」≠「问题不存在」**；**判据要盯正确对象**；**否决条件只对真判据生效**；**台账按证据记，允许偏离 Lead 摘要但写理由**；**测量工具会撒谎**（累计 5 次）；**同一列两种相反语义会互相抵消**；**不变量有适用范围**；**没有 dump 不归因产品**；文档与实测要对账；验收用链内同形式；收紧判据后复验原反例；守卫防「先咬自己」；**守卫头注要与实现一致**；前缀式清理/固定临时路径是并行互杀源；样本量不足的绿不算绿；「期望值同源」≠ oracle 成立；假 oracle 要删；抖动段不挂门禁；基线撞上限不许调上限；**基线只来自真跑**；一次只改一个文件；定位代码块只用 CodeGraph；断言源码文本必须登记；`git add` 显式路径；遇 `index.lock` sleep 2s 重试；**禁 `pkill -f`**。
