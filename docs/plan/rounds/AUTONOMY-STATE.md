## 纪律（并行版）
只信「命令 + 真实 exit code」；未跑标 `unverified`；**判据必须能红**；**先核对被测签名再判定「不一致」**；**对照断言只证「重构未改行为」**；**错误码/错误文案都属对外可观测接口 ⇒ 变更前先查依赖面、尽量逐字保持**；**尾点/大小写/百分号编码/IDN 是同族坑**（`new URL()` 会把前两者里的编码与 IDN 归一到 `localhost`）；**降级/跳过必须显式打印**；**链必须在无在途改动时跑**；**作者中断≠改动作废（Lead 定向验收后收编）**；一次只改一个文件 + `node --check` + 失败即回滚；定位代码块只用 CodeGraph；断言源码文本必须登记；`git add` 显式路径；遇 `index.lock` sleep 2s 重试；**禁 `pkill -f`**。
