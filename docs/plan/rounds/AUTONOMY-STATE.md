## 注释纪律（本轮双切片独立发现，已入 `AGENT_HANDOFF`）

注释只允许「现在 / 禁止 / 过去且已闭环」三种时态；**禁用「将来应该」**——
没人负责注销，到期即变成带指令性的假话。机械判据：
非 TODO 注释里 `grep -E "应改为|待回收|将来|重导出之后"` 命中即需人工确认。
