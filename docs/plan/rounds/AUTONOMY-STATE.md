## 教训（455–456，接 454）
- **455「『CI 独有』不等于『本地跑不了』—— 两者之间差的往往只是一次 `npm install`」** —— 26 个脚本此前从未在本机执行，只因 R233 前 `packages/*` 没依赖；装齐后**一次全过**。⇒ 判据归类时，「需要真机」必须**有具体理由**（redis/docker/多进程/外部服务），否则它只是**没人试过**（实测：需 docker 仅 3 个 + PG 1 个，其余 22 个纯静态）。
- **456「生成器跑通 ≠ 验证通过，必须看 `git status`」** —— `gen:protocol` 类脚本是**写文件**的，exit 0 只说明它跑完了；真判据是**「生成结果与已提交一致」**（`git status` 空 = 幂等）。⇒ 对生成器类，「绿」要看**副作用是否为零**，不是看退出码。
