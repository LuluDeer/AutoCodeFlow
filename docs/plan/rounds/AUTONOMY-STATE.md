## 教训（408–409，接 407）
- **408「『验证到纯函数 + 读法』不等于『验证到端点』」** —— 中间还隔着注入、守卫、拦截器、响应整形。⑥（字段齐全）与 ⑤（信封）若没测，一个 `@Res()` 误用或 DTO 漏字段就能让纯函数**全绿**而端点**全错**。⇒ 验证**深度**按「证据链还剩几层没覆盖」判定，不是按「跑过真 Redis」。
- **409「构造陷阱：不要在生产用的活动队列上造异常态」** —— 真实 processor 会秒消费掉你塞的 job，你**根本造不出**「卡住」；改写生产数据更不可接受。⇒ 换一条**可安全复原**的真实入口（pause）验证同一段判断，并**如实说明**换了哪个形态、没覆盖哪个。
