## 教训（266–269）
- **266「绿」不等于「自检被跑到」**：摘掉 selftest 调用后 `lint:i18n` **仍 0**、输出**无 selftest 行** ⇒ 退出码只证明主判据过。接线类改动的判据是「**输出里有没有那一段**」，「摘掉后仍绿」要**当场做一次**（本轮用旧入口的等价命令复现，不改文件）；
- **267 跨包复用的三种否决理由要分开写**：**结构性不可行**（TS6059 / 只有 `dist`）= 硬否决；**语义不对**（建议会误导）= 真否决；只有「**耦合不好看**」是**偏好**。把偏好写成硬否决会绕远路，把硬否决写成偏好会被「优化结构」推翻；
- **268 兜底映射必须「未知即原样」**：未知 / 无码 / 原型链键 ⇒ `null` ⇒ 既有输出**逐字节不变**，否则一次「优化查表」就把未知码**悄悄吞进默认分支**（旧用例感觉不到）。配套：关掉映射时已知码**必红**、未知码**仍绿**；
- **269 第二份事实源要自带复核命令与同步提示**：头注列事实源位置 + `grep` 命令 + 「新增/改名两边都要看」；**不做全量表**（必然腐化）。**同步仍靠人 ⇒ 无 CI 守卫即登记为遗留**，不装成已有。
