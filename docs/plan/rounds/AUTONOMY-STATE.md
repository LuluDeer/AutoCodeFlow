## ADR-038 步骤 1 的**自我纠正**（`5ac4b812`，W3）—— 值得记的方法学
- **J1（字面判据：广播后每台计数 ≥1）⇒ 绿**。但这不是「C 段不成立」，而是**判据选错了对象**：J1 量的是**计数**（广播后本来就是 1，`:6034`，既有 `R-06` 早已钉住），而 C 段说的是 **`计数1 / 行数0`**（行数口径）。
- **真判据 J2**（已实测**红**）：广播 `+1` 后让该机**上报 0 且零条非终态行** ⇒ 下限 `GREATEST(0, 0) = 0` ⇒ **抹掉广播那 1**；断言原文 `Expected pattern: not /SELECT count\(\*\) FROM task_executions/`，实得 `GREATEST(0, (SELECT count(*) …))`。
- **裁决**：**J2 认作步骤 1 判据**，J1 留作回归哨兵；要求把「J1 为何不够 + J2 才是真判据 + 否决条件的正确用法（J1 绿不触发否决；**将来 J2 变绿才停手重查**）」补进 ADR。**J2 随步骤 3 一起入库**（不留红用例）。

## 方法学（累积，本轮新增标 ★）
只信「命令 + 真实 exit code」；**「判据没红」≠「问题不存在」**（★J1 量错对象）；**判据要自带否决条件**，且**否决条件只对真判据生效**；**语义分离优于消灭特殊性**；**失效半径要写方向性**；**同一列两种相反语义会互相抵消**；**不变量有适用范围**（只对单播）；**没有 dump 不归因产品**；**测量工具会撒谎**（本轮累计 5 次：`signal` 缺失 / 失败行正则 / 判据方向 `!==` / 删行记账 / 假 oracle `--fixed`）；harness 与产品缺陷必须分栏；不变量要写成断言；记账口径要对齐生产；不编造 sha；文档与实测要对账；验收用链内同形式；收紧判据后复验原反例；守卫防「先咬自己」；前缀式清理/固定临时路径是并行互杀源；样本量不足的绿不算绿；「期望值同源」≠ oracle 成立；假 oracle 要删；抖动段不挂门禁；基线撞上限不许调上限；强/弱反向验证分开记；先看 `signal` 再判退步；一次只改一个文件；定位代码块只用 CodeGraph；断言源码文本必须登记；`git add` 显式路径；遇 `index.lock` sleep 2s 重试；**禁 `pkill -f`**。
