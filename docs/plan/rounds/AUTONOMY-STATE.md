**方法学 532**：**「用单一手段的失败推断系统性质」是一种同形错误**。
本轮它在三处以三种面貌出现，都指向同一个判据缺失：
- B 判「归因链断了」← 只试了 `blame`，没试 `show`（**工具维度**）
- 反证只红一条就以为缺陷被覆盖 ← 没问「被测代码是否根本没跑到」（**层级维度**）
- 等 `inbox-page` 就以为页面就绪 ← 没问「该节点在 loading 期是否也存在」（**时序维度**）

⇒ **共同判据**：说「X 不可用 / 已覆盖 / 已就绪」之前，先列出**你试过哪几种手段**；
只试了一种，结论只能写到「在我试的这条路上没有」。
这与方法学 507（「我搜过了」要带上「我搜了哪一层」）是同一条纪律在三个新维度上的展开。
