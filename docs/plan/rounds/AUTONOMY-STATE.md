## 教训（414–415，接 413）
- **414「触发异常的三条路：挂起 / 重连 / 真失败」** —— 只有**权限拒绝**能测「读失败」分支；用挂起冒充失败，测出来的是**超时行为**。
- **415「验证『降级』标志时必须配一条对偶断言」** —— 只测「读失败⇒degraded」会漏掉最危险的实现：**一律降级就一律不报**（把真停摆静默掉）。必须断言「同一降级条件下，真的那件事仍然成立」。
