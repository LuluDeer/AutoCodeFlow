## 方法学（累积，本轮新增 ★）
只信「命令 + 真实 exit code」；**同一份数据比对方向错了也会造出假违反**（★`!==` vs 单侧判据）；**测量工具会撒谎**（第 N 次）；**harness 缺陷与产品缺陷必须分栏**（`verdict: product|harness`）；**不变量要写成断言**，否则它只活在代码顺序里、下一个重构打破它无人知晓（★ADR §5b 新增 `计数 ≤ 行数`）；**不编造 sha**（连派发消息也不行，本轮已被 W2 的 `git cat-file` 挡住）；**文档与实测要对账**；验收一律用链内同形式；收紧判据后要复验原反例仍被抓；守卫防「先咬自己」；前缀式清理/固定临时路径是并行互杀源；样本量不足的绿不算绿；「期望值同源」≠ oracle 成立；同源签名 = 反向验证同时击穿判据层与产品层；修前先证窗口可达；假 oracle 要删；抖动段不挂门禁；基线撞上限不许调上限；强/弱反向验证分开记；先看 `signal` 再判退步；一次只改一个文件；定位代码块只用 CodeGraph；断言源码文本必须登记；`git add` 显式路径；遇 `index.lock` sleep 2s 重试；**禁 `pkill -f`**。
