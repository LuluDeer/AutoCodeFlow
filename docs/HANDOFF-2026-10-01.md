## 行为契约变化（你那边的代码若基于旧契约会静默错，重点核对）

1. **tasks.dependencies 契约翻转**：map 从 `{上游uuid: 上游显示名}` 改为 **`{显示名: 上游uuid}`（value 才是依赖任务 id）**。存量数据由迁移 1790000000048 幂等翻转。任何直接读写该列的脚本/工具都要对齐。
2. **派发载荷白名单化**：admin → 执行器的 `task` 对象从整实体收敛为 14 个字段 + `packageUrl`（protocol TaskConfig ∪ 三端读取面）。`webhookSecret/secrets/ownerUserId/alarm*` 等 26 列不再下发。**若你有自定义执行器代码读取白名单外的 task 字段，会拿到 undefined**。
3. **部署 runMode 缺省从 DAEMON 改为 ONCE**（对齐 Web 语义）；MCP/CLI 部署调用不显式传 runMode 的行为随之变化。
4. **BullMQ priority 方向修正**：DB/UI 的 4=紧急 现在正确映射为 BullMQ 高优先级（此前倒置）。
5. 前端 `TaskExecutionStatus` 联合类型新增 `'waiting'`（互斥/部署约束排队态，开放态可终止）。
6. update 任务新增可选 `expectedUpdatedAt`（乐观锁，不传则跳过检查——MCP/CLI/SDK 旧调用零影响，但 409 语义已存在）。

## 新增的工程纪律（在你那边改代码前必读，CI 会拦）

- **迁移纪律**：①迁移文件内**只准导出 MigrationInterface 类**——导出纯函数会被 TypeORM 当迁移候选报 "Object migration name is wrong"（真实踩坑）；②新迁移先在 `docs/PLAN-CLAIMS.md`「迁移时间戳分配表」登记再建文件（check-migrations 拦截）；③实体命名 `@Index` 必须与迁移 DLL 一致，check-index-drift 已支持 CONCURRENTLY；④`migration:run/revert` 现在走 `migration-lock-cli`（pg_advisory_lock 互斥），第二次 run 必须输出 "No migrations are pending"（CI 幂等守卫依赖此文案）。
- **API 契约变更**：`npm run swagger:export` 与 admin-web 的 `npm run gen:api-types` **两个产物都要重新生成并同批提交**（api-types-drift job 双向比对）。
- **改了 `apps/executor-node/src`**：须重打 desktop 内嵌 bundle 并回填 `apps/executor-desktop/executor-node-bundle.sha256`（语义摘要本地可复现，字节哈希以 CI Ubuntu 为权威）。
- **shell 脚本**：变量名后禁止紧跟多字节字符（`$var，` 会被 macOS bash 3.2 吞坏），check-shell-multibyte-var 拦截，`--fix` 可自动修。
- **admin-web**：禁止裸中文界面串（i18n 守卫）；改 DTO 后相关测试的源码契约断言（app-deployment-delete-record 等会 grep 后端源码）需同步。
- Python 四库（autocodeflow-http/ai/db/notify）已纳入 release-please（0.2.0 基线），改它们要走版本纪律。
